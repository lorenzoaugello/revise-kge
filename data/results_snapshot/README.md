# Archived run records

These CSVs are the raw per-seed records supplied for the paper's main mixed-update experiments and reduced ablation grid. Filenames have been normalized to dataset/model/scenario/seed. They are archival outputs, not inputs to training. The main records cover 4 datasets × 3 models × 5 seeds.

The `summary/` subdirectory contains derived CSV summaries generated from these archived records. `manifest.csv` records file sizes and SHA-256 hashes for each raw run CSV.
